## 取用与调整

- [整套预览](preview.jpg)：仅供比较背景，不是卡片或分享页设计。
- [backgrounds.drawio](backgrounds.drawio)：八页可编辑源文件，每页内嵌对应背景；原始背景独立分层，候选内容区参考线与可选浅化遮罩各自分层并默认隐藏。
- [manifest.json](manifest.json)：以实测像素尺寸为准，含校验值与候选低细节区域。
- [prompts.json](prompts.json)：完整提示词、预期尺寸与构图意图。
- [history.json](history.json) 和 `records/`：逐次执行记录、实际尺寸、来源及 SHA-256。

内容区域按归一化坐标记录，表示背景留白的大致位置，不是前端合成的最终槽位。后续在 draw.io 中放置现有透明角色图、官方 Beyond Context 字标、可编辑文字、四维图和程序生成的二维码，再确定精确位置。

本批像素尺寸用于素材取用；实物卡成品尺寸、裁切、出血和正文可读性在排版阶段确定。v1、v2 与原角色定稿继续保留。
