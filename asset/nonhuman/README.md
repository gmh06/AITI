## 本轮设计要求

- 从原拟人／娘化参考中沿用配色、眼睛、少量标志性饰品和细线淡彩画风，身体采用完整非人形结构。
- 七款均不保留服装；人的长发不转换成鬃毛、发型或附着在身体上的大块毛发，使用正常鳞片、毛被或光滑皮肤。
- 猫的异色瞳按物理左右保持：正面画面左侧紫红、右侧金色；左侧面可见金眼，右侧面可见紫红眼。
- 狐狸保留眼罩，不保留耳侧挂饰；小恶魔无头发，角采用天然角质感而非金属，金属效果仅保留在王冠等饰品上。
