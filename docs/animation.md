# 动画设计

本文是揭晓动画的修订版设计，已按[系统设计](system/design.md)第四节第 4 小节的接口和技术限制解决原稿中的冲突。原稿及冲突清单见[动画设计 · 原稿](animation_original.md)，修改对照见第八节。

## 一、定位

```
首页 → 答题 Q1..Q10 → 揭晓动画 → 结果页 → 电子卡页 → 保存分享图
```

- 第 10 题作答后进入揭晓。结果此时已经算出，动画只负责呈现，风格是“抽卡或开盲盒式的短动画”。
- 正常时长 3.0 秒，不含等待角色图加载的时间。
- 只使用无文字版角色图。
- 手机和电脑使用同一套时间轴，位置按各自布局的实际坐标计算。

## 二、核心思路

1. **局部窥视代替放大特写**。原稿把角色图放大 5.5 倍做特写，源图宽度不够，画面一定发糊。修订版让角色图始终保持 1 倍或更小，只通过一个圆形窥视孔露出局部：先让人看到清晰的一小块，再把孔扩开露出全身。
2. **去噪用低清副本叠化**。模糊效果不靠逐帧改 `blur` 半径，而是在角色图加载完成后，于运行时把它画到宽 16 px 和 64 px 的两个小 canvas 上，按原图尺寸拉伸显示。浏览器拉伸小图时自然就是模糊的，三层依次淡入即可呈现由粗到细的去噪过程。
3. **大面积只动 `transform` 和 `opacity`**。这两个属性由合成线程处理，不触发重排和重绘，在中低端安卓上也能保持流畅。唯一的例外是窥视孔的 `clip-path`，它只作用在角色图元素上，面积不超过角色图本身。
4. **结束帧就是结果页第一帧**。揭晓和结果页渲染同一套结果页布局，揭晓时只是在这套布局上叠加动画。动画全部结束或被取消后，元素回到自身的样式，也就是结果页的样子，中间不切换画面。

## 三、时间轴

除特别注明外，各阶段首尾相接，没有重叠。

| 时间（秒） | 阶段 | 画面 | 实现要点 |
| :--- | :--- | :--- | :--- |
| 0.00–0.10 | 噪声建立 | 白色页面中央浮现颗粒噪声，约占屏宽 70% | 噪声层 opacity 0→1 |
| 0.10–0.50 | 噪声跳动 | 噪声持续变化；顶部文案淡入 | 噪声层每 40 ms 跳到一个随机偏移（translate，`steps` 缓动）；文案 opacity 0→1，300 ms |
| 0.50–0.60 | 蓄力 | 噪声一次明暗脉动 | 噪声层 opacity 0.85→1→0.85，scale 1→1.04→1 |
| 0.60–0.80 | 去噪开始 | 窥视孔内浮现模糊色块 | 噪声 opacity →0.5；16 px 副本 opacity 0→1 |
| 0.80–1.10 | 去噪中段 | 色块出现结构，仍认不出内容 | 噪声 opacity →0；64 px 副本 opacity 0→1 |
| 1.10–1.20 | 去噪完成 | 窥视孔内画面完全清晰；文案淡出 | 原图 opacity 0→1；文案 opacity 1→0 |
| 1.20–1.60 | 窥视静止 | 一小块清晰的局部，只做极轻的呼吸 | 窥视孔半径 r→1.03r，linear |
| 1.60–1.90 | 展开 | 窥视孔迅速扩开露出全身，角色同时移到结果页中的位置 | 半径扩到覆盖整张图；外层位移归零；300 ms，`cubic-bezier(0.16,1,0.3,1)`；闪白 opacity 0.5→0，1.60–1.72 |
| 1.80–2.00 | 落定 | 角色轻微下沉后回弹 | 内层 scale 1→0.97→1。与展开末段重叠 0.1 秒，有意为之 |
| 2.00–2.30 | 人格名 | 人格名落下 | translateY −12px→0，scale 1.04→1，opacity 0→1 |
| 2.30–2.70 | 四维条 | 四条依次填充到目标长度，字母和极名随条出现 | 每条 scaleX 0→1，220 ms，间隔 60 ms；`transform-origin` 设在生长起点 |
| 2.70–3.00 | 描述与其余内容 | 描述上移淡入，按钮等其余内容同时出现 | translateY 8px→0，opacity 0→1 |

过程中的文案：0.10–1.10 秒显示 `正在读取你的 10 个选择…`，1.10 秒起淡出，窥视阶段完全留白。

窥视阶段（1.20–1.60）把角色图整体平移，使窥视孔中心落在视口中央；展开时再移回结果页中的位置。平移和窥视孔都跟着同一个元素走，所以孔内画面不会错位。

四维条的目标长度取自结果页四维条本身（长度比例为 |得分| ÷ 7），动画只是它的入场，最终长度不由动画决定。

## 四、等待与异常

| 情况 | 行为 |
| :--- | :--- |
| 0.60 秒时角色图尚未加载完 | 停在噪声跳动阶段循环，文案继续显示；加载完成后从蓄力阶段（0.50）接着播放 |
| 进入揭晓后 8 秒仍未加载完 | 结束揭晓，进入结果页，显示加载失败与重试 |
| 角色图加载出错 | 立即结束揭晓，进入结果页，显示加载失败与重试 |
| 点击或触摸任意位置 | 立即结束揭晓，进入结果页 |
| 电脑上按 Enter、空格或 Esc | 同上 |
| `prefers-reduced-motion: reduce` | 不播放，直接进入结果页 |
| 揭晓中旋转屏幕或窗口跨过布局阈值 | 立即结束揭晓。各元素的位置在开始时按布局算好，布局一变就不再准确 |
| 揭晓中切到后台（`visibilitychange` 变为 hidden） | 立即结束揭晓，回来时直接看到结果页 |

“结束揭晓”统一指：取消所有进行中的动画，派发 `REVEAL_DONE`。取消后元素回到自身样式，不残留中间状态。电脑上结束后，焦点移到结果页的人格名（系统设计第八节第 3 小节）。

角色图在第 10 题作答后才开始预加载（系统设计第四节第 5 小节），噪声阶段的 0.6 秒正好作为加载窗口。

## 五、8 个角色的窥视取景

窥视孔里的局部要有辨识度，但看不出是谁。除 DeepSeek 和 Gemini 取角色自身外，其余只取道具，尽量少露出角色。

| 角色 | 窥视对象 | 类型 |
| :--- | :--- | :--- |
| GPT | 图纸一角：图框、细网格、折角 | 道具 |
| DeepSeek | 鲸尾 | 角色自身 |
| Claude | 案卷封套的装订边 | 道具 |
| Kimi | 手风琴折页的连续折痕 | 道具 |
| Gemini | 一只眼睛（异色瞳） | 角色自身 |
| GLM | 键盘，几个键帽被压住 | 道具 |
| Grok | 气球：紧绷、被顶出一处凹陷 | 道具 |
| 豆包 | 奶茶杯口：封膜、吸管孔 | 道具 |

三张纸要区分开：GPT 是冷白底加灰色网格的工程图纸；Claude 是米黄纸加装订孔的正式案卷；Kimi 是偏白纸带加等距竖直折痕的折页。三者容易混淆，这本身有利于制造悬念，但各自的材质必须成立。

由于画面不放大，窥视对象在角色图中必须本身就足够大，能在 1 倍下看清。半径建议在图宽的 12%～20% 之间；以手机上角色图宽约 340 CSS px 计，对应直径约 80～135 CSS px。

## 六、实现方式

| 项 | 方式 | 理由 |
| :--- | :--- | :--- |
| 时间轴 | Web Animations API（`element.animate`），不引入动画库 | 需要等图、中途接续和随时取消，纯 CSS keyframes 难以控制；`cancel()` 后元素自然回到结果页样式。iOS Safari 15+ 均支持 |
| 噪声 | 运行时用 canvas 生成一张 128 × 128 的灰度噪声图，平铺在噪声层上；只做平移跳动 | 噪声只计算一次，之后每帧只是移动一个合成层 |
| 去噪 | 角色图加载后，运行时生成 16 px 和 64 px 宽的两个副本，与原图叠放并依次淡入 | 不动画 `filter: blur()`，也不需要额外的图片文件 |
| 窥视孔 | 角色图元素上的 `clip-path: circle()` | 作用面积只有角色图本身 |
| 位移与缩放 | 外层元素做平移，内层元素做缩放 | 两组动画写在不同元素上，`transform` 不互相覆盖 |
| 四维条 | `transform: scaleX()` | 动画 `width` 会每帧重排 |
| 取景参数 | 界面层中单独的一个数据文件 | 校准时只改一处 |

噪声层、低清副本和闪白层都是装饰元素，设 `aria-hidden="true"`。

## 七、验收要点

在[测试与验收](system/verification.md)第二节的基础上，揭晓动画另外检查：

- 中低端安卓手机上全程流畅，没有明显卡顿。
- 窥视阶段孔内画面清晰，展开后的全身图与结果页中的完全一致，结束时没有跳动或闪烁。
- 8 个角色的窥视对象都能看清，同时猜不出是哪个角色。
- 揭晓过程中点击、按键、旋转屏幕、切到后台，都会直接进入结果页，且没有残留的模糊、裁切或位移。
- 限速网络下噪声阶段会等图；断网时 8 秒内进入结果页并显示重试。

## 八、相对原稿的修改

| 原稿的问题 | 修改 |
| :--- | :--- |
| 5.5 倍放大特写会发糊 | 改为 1 倍下的圆形窥视孔，全程不放大清晰的原图；只有本身就模糊的低清副本被拉伸 |
| 逐帧变化的 `feTurbulence` 和 `feDisplacementMap` 覆盖大面积 | 噪声改为一次生成、只做平移的平铺图；位移效果改为 opacity 与 scale 脉动 |
| 用 `blur` 半径做去噪 | 改为低清副本叠化 |
| 等图没有上限 | 8 秒超时进入结果页并显示重试；加载出错时立即进入 |
| 只能点击跳过 | 增加 Enter、空格、Esc，以及旋转、窗口跨阈值、切到后台时自动结束 |
| 拉远、过冲、回弹、定格的时间互相重叠 | 重排为首尾相接，只保留“落定”与“展开”末段的 0.1 秒有意重叠 |
| 四维条“每条 300 ms、间隔 80 ms”放不进 0.3 秒 | 改为每条 220 ms、间隔 60 ms，共 0.4 秒 |
| 人格名动画改字距，每帧重排 | 改为 scale 1.04→1 |
| 0.8 秒处“顶部文案切换”没有写切换成什么 | 只保留一句文案 |
| 连续掉帧时降级为简版 | 删除。动画只用合成线程处理的属性，主线程 `requestAnimationFrame` 测到的帧耗时不能反映它是否卡顿；真机验收确认流畅即可 |
| 不支持 `backdrop-filter` 时用纯色替代 | 删除，修订版不使用 `backdrop-filter` |
