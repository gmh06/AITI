# AITI 活动策划案

## 一、活动概况

- **所属活动**：清华大学计算机科学与技术系第44届学生节，主题为 Beyond Context。
- **路演时间**：2026年11月27日，11:00—13:00、17:00—19:00。
- **路演地点**：C楼前广场。
- **学生节演出**：11月29日，大礼堂。
- **面向人群**：以清华同学为主，题目融入校园生活和计算机系特色。
- **活动形式**：完成趣味人格测试，获得匹配的AI角色与电子纪念卡；路演现场可领取对应的实物卡。
- **活动目标**：首先提供有趣、顺畅的参与体验，同时加深同学对学生节的印象，通过结果分享继续传播。

Beyond Context 贯穿题目、结果和卡片：呈现参与者在不同情境下的选择与多个侧面，鼓励大家在已有经历的基础上，看见更大的世界、尝试新的可能。

## 二、参与流程

1. **进入测试**：手机扫码或访问网址，也可使用现场电脑；无需填写昵称，直接开始。
2. **完成答题**：回答约5～10道带有清华和计算机系生活特色的题目。
3. **揭晓结果**：前端按规则即时计算结果，再播放一段抽卡或开盲盒式的短动画，揭晓匹配的AI。
4. **查看与保存**：查看人格结果和电子卡，保存分享图，或把页面链接分享给他人。电脑参与者可扫码把页面带到手机上。
5. **现场领卡**：在路演时段到摊位展示结果，领取对应AI的实物卡，每人一张，无需额外互动。发放和库存由现场人员独立管理。

测试允许重复参与，不保存任何测试记录；实物卡的领取规则单独执行，尽量一人一张。

## 三、AITI系统

系统为纯前端静态站点，包含参与者使用的前台和现场公共展示页。不设后台，不收集、不保存测试记录。前台适配手机、电脑；公共展示页支持全屏显示。

### 1. 前台与结果页

- 提供答题、结果揭晓、结果查看、电子卡保存和结果分享功能。
- 结果页展示匹配的AI角色、人格名称和该人格固定的描述文案，四维特征以图示呈现。
- 文案可以有善意吐槽和反差幽默，既让人愿意认领角色，也能发现自己的其他侧面。
- 结果完全由答案按规则决定，同一组答案始终得到同一结果；不针对具体答案生成额外解释。

### 2. 题目与匹配方式

- 先手工编写约5～10道题及选项，再与AI讨论、测试和迭代。
- 使用预先确定的规则，在前端把答案映射到 AITI 人格，并据此展示对应文案；目标为提交后秒级出结果。
- 若各模型自行答题的结果有足够区分度，可将其作为匹配校准依据，探索交叉熵等候选评分方式，并在结果页附上模型自身的测试结果供参考。
- 模型自测与相关评分方法属于可选增强，不影响基础规则方案交付。
- 题目、匹配规则和文案随站点版本一起发布，已发布的版本不再改动。

### 3. 现场公共展示页

- 持续展示活动名称、简短玩法说明、领卡方式、测试二维码和简短网址。
- 轮播学生节主视觉、AI角色介绍和示例卡片。
- 与电脑上的个人答题页面分开运行，需要演示时可临时切换。

## 四、纪念卡片与视觉

### 1. 电子卡与分享图

- 网页中的卡片可翻转：正面展示对应AI的形象；背面展示该AI角色的描述、学生节信息、测试入口和 Beyond Context 寄语。
- 分享图按AI角色预先制作，共8款，内容与实物卡一致，包含角色、该角色的描述、主题寄语、测试二维码及11月29日学生节信息，用户可直接保存。
- 手机用户可直接保存图片，电脑用户可扫码在手机上打开站点后保存。

### 2. 实物卡

- 按AI角色制作固定款式，共8款，整体内容和视觉与电子卡一致。
- 正面为AI形象、角色语言或行为；背面为学生节信息、AITI二维码和主题寄语。
- 参与者展示手机或电脑上的结果后，现场人员发放对应款式，每人一张。
- 中午、傍晚两场分别预留库存；各款数量及缺货处理方式在物料落实时确定。

### 3. 统一视觉与表达

- 网站、结果页、卡片和现场展示均遵循本届学生节主视觉，融入清华及计算机系元素。
- 每个AI使用固定、统一的形象，人形与非人形两套方案并行，上线前确定其中一套；可搭配模型图标等辅助元素。
- 题目和文案以清华同学容易理解的生活情境为基础，通过贵系特色和幽默增加辨识度。

## 五、现场安排

**所需物料**：显示屏、1～2台体验电脑、AITI网站、二维码与网址展示物、各款实物纪念卡，以及相应供电和网络。

1. **每场开始前**：打开公共展示页和电脑答题入口，检查扫码、完整答题、结果与卡片保存是否正常，备好本场卡片。
2. **活动进行中**：引导同学手机扫码或使用电脑，协助查看和保存结果，按对应AI发放卡片。电脑体验结束后回到首页，供下一位使用。
3. **两场之间及结束后**：整理剩余卡片，检查设备和系统状态，为下一场或后续线上访问做好准备。

## 六、当天及之后的传播

- **11月27日路演当天**：开放测试，通过大屏、现场二维码、网址和参与者分享传播。引导用户保存电子卡、邀请朋友测试，并到现场领取实物卡。
- **路演后至11月29日演出前**：继续开放线上测试和结果分享，结合角色卡与校园趣味文案传播，并突出学生节演出信息。
- 演出后的开放期限和保留功能，结合实际运行条件确定。

## 七、待落实事项

- **内容**：最终题库、人格维度与匹配规则；卡面描述文案（按AI角色统一撰写，需与人格结果页区分）；卡面排版与文字篇幅。
- **现场**：设备、供电、网络及人员安排；断网或服务异常时的备用流程。
- **物料**：卡片规格、各款印量、两场配额、缺货处理、制作时间与预算。
- **技术**：技术栈、静态托管方式、访问地址与国内可访问性、图片资源优化。
- **活动信息**：演出地点为大礼堂；不设入场方式与官方信息入口。
- **交付安排**：可演示版本、内容定稿、印刷交付和演出后服务保留的时间节点。
