本文汇总此前方案文档中的动画设计。内容取自已删除的 `docs/system/pages.md`、`tech.md`、`overview.md`、`plan.md`（最后版本见提交 `9583bd6`），以及 [活动策划案](Activity_draft.md) 和 [无文字版角色图](art/textfree-assets.md)。

## 一、动画在流程中的位置

```
首页 → 答题 Q1..Q10 → 揭晓动画 → 结果页 → 电子卡页 → 保存分享图
```

- 第 10 题作答后进入揭晓，前端已算出结果，动画只负责呈现。活动策划案中的定位是“抽卡或开盲盒式的短动画”。
- 时长 3.0 秒，点击任意位置立即跳到结束帧。
- 揭晓动画和结果页的角色图都使用无文字版。
- 其他动效在原文档中只提到电子卡“可翻转”，没有具体设计。

## 二、揭晓动画分镜

从 0.6 秒重噪声开始收敛时，画面已经在 5.5 倍裁切视图上，去噪完成即得到局部特写；随后的拉远是把同一个元素从 5.5 倍缩回 1 倍。

| 时间（秒） | 阶段 | 画面 | 实现要点 |
| :--- | :--- | :--- | :--- |
| 0.0–0.1 | 噪声建立 | 全白页面中央浮现颗粒噪声，约占屏宽 70% | SVG `feTurbulence` 叠加，种子每 40 ms 变化 |
| 0.1–0.5 | 噪声跳动 | 噪声持续变化，顶部小字淡入 | 文案 opacity 0→1，300 ms |
| 0.5–0.6 | 蓄力 | 噪声幅度短暂增强，一次明暗脉动 | `feDisplacementMap` scale 80→100→80 |
| 0.6–0.8 | 去噪开始 | 噪声收敛，底层图像从模糊中浮现 | displacement 100→0（400 ms）；blur 40→24 |
| 0.8–1.1 | 去噪中段 | 色块出现结构，仍认不出内容 | blur 24→10；顶部文案切换 |
| 1.1–1.2 | 去噪完成 | 画面完全清晰 | blur 10→0 |
| 1.2–1.6 | 特写静止 | 局部特写定格，只做极轻的呼吸 | scale 5.50→5.61（相对 +2%），linear |
| 1.6–1.9 | 猛拉远 | 画面急剧缩回全身 | scale 5.61→1.0（300 ms，`cubic-bezier(0.16,1,0.3,1)`）；blur 24→0；闪白 opacity 0.5→0（120 ms） |
| 1.85–1.95 | 过冲 | 缩到 0.97 | 100 ms |
| 1.95–2.05 | 回弹 | 回到 1.0 | 100 ms |
| 2.0–2.4 | 定格与人格名 | 角色静止，人格名落下 | 人格名 translateY −12px→0 并淡入，400 ms；字距 0.2em→0.05em |
| 2.4–2.7 | 四维条就位 | 四条依次填充到目标长度 | 每条 300 ms，间隔 80 ms |
| 2.7–3.0 | 描述淡入 | 描述文字上移淡入 | 400 ms |

过程中的文案：

- 0.1–1.1 秒显示 `正在读取你的 10 个选择…`
- 1.1–1.2 秒起淡出，特写阶段完全留白

## 三、结尾与结果页的衔接

动画不是独立的遮罩层，而是结果页里那张角色图自身的入场变换：同一个 DOM 节点从“5.5 倍放大 + 模糊 + 位移”变回原位。所以动画的结束帧就是结果页的第一帧，不需要切换画面，也不会闪一下。

四维条的填充（2.4–2.7 秒）同样是结果页四维条自身的入场，填充的目标长度为 |得分| ÷ 7。

## 四、降级

| 情况 | 行为 |
| :--- | :--- |
| 目标角色图未加载完 | 停在噪声阶段，文案继续显示；加载完成后才进入去噪 |
| 点击或触摸任意位置 | 立即跳到结束帧，进入结果页 |
| `prefers-reduced-motion: reduce` | 不播放动画，直接显示结果页 |
| 连续掉帧（超过 10 帧单帧耗时 > 32 ms） | 降级为“淡入 + 轻微缩放”的简版 |
| 不支持 `backdrop-filter` 等新特性 | 用纯色替代，不阻塞流程 |

图片加载的配合：首屏不加载角色图；第 10 题作答后立即预取目标角色图，噪声阶段正好作为加载窗口。

## 六、原定的实现方式

| 项 | 原方案 | 理由 |
| :--- | :--- | :--- |
| 动画实现 | 纯 CSS keyframes，不引入动画库 | 3 秒分镜是固定脚本；少一个依赖，约少 50 KB |
| 滤镜 | SVG `feTurbulence`、`feDisplacementMap` 加 CSS `blur` | 噪声与去噪效果 |
| 取景参数 | 单独文件 `lib/crop.ts` 存放 8 组参数 | 校准时只改一处 |

原验收要求：动画正常播放，点击可跳过，跳过后不残留动画状态。

## 七、与当前系统设计的冲突

[系统设计](system/design.md)第四节第 4 小节规定了揭晓的接口和技术限制。原分镜有以下几处与之冲突，界面设计时需要修改：

| 冲突 | 原分镜 | 系统设计 | 说明 |
| :--- | :--- | :--- | :--- |
| 特写清晰度 | 5.5 倍局部特写，要求“画面完全清晰” | 揭晓效果不应依赖清晰的局部放大 | 角色图源文件宽 1024 px。以宽 390 CSS px、`devicePixelRatio` 为 3 的手机为例，5.5 倍时屏幕上 1170 个物理像素只对应源图约 186 px，放大约 6 倍，必然发糊。除非单独提供高清裁切图，否则特写方案不可行 |
| 噪声滤镜 | `feTurbulence` 种子每 40 ms 变化，覆盖约 70% 屏宽 | 不对大面积区域使用逐帧变化的 SVG 滤镜 | 中低端安卓上会掉帧 |
| 等图上限 | 未加载完就一直停在噪声阶段 | 超过 8 秒进入结果页，显示加载失败和重试 | 原方案没有超时，网络差时会卡在动画里 |
| 键盘跳过 | 只写了点击或触摸 | 电脑上按 Enter、空格、Esc 也可跳过 | 需补充 |
| 时间轴 | 拉远（至 1.9）与过冲（自 1.85）、回弹（至 2.05）与定格（自 2.0）有重叠 | 无 | 重叠是否有意需要确认 |
