# AITI ”人格“分类

## 一、四维指标定义

### D1 认知内核（Core Engine）：`L` 逻辑工程 vs. `H` 人文表达

刻画模型与个体在接收信息、处理任务时的底层优势领域。

| 类别 | 代号 | 模型层面特征 | 拟人化特征 |
| :--- | :--- | :--- | :--- |
| **逻辑工程** | `L` (Logic-Driven) | 擅长硬核工程、代码攻坚、底层推演与犀利交锋 | 遇事优先拆解因果链条与技术细节，看重逻辑密度与解决效率 |
| **人文表达** | `H` (Humanities-Driven) | 擅长自然语言写作、版式审美、长文脉络与情绪共鸣 | 对文字质感、人际分寸与情绪氛围极其敏锐，擅长叙事与共情 |

### D2 思考倾向（Thinking Latency）：`D` 深度思考 vs. `Q` 即时直觉
对应认知科学中的 **System 2（慢思考）** 与 **System 1（快响应）**，刻画思考深度与算力消耗倾向。

| 类别 | 代号 | 模型层面特征 | 拟人化特征 |
| :--- | :--- | :--- | :--- |
| **深度思考** | `D` (Deep-Think) | 偏好长上下文精读、多步推理、深入证实和狂炫 Token | 习惯先做全盘推演和深度论证再下结论，容易陷入“过度思考” |
| **即时直觉** | `Q` (Quick-React) | 偏好低延迟直给、条件反射式回复、指哪打哪和即时玩梗 | 反应敏捷、行动派、直觉流，倾向于快速给出反馈或立刻上手 |

### D3 对齐模式（Alignment Guardrail）：`R` 准则自持 vs. `U` 破界无忌

刻画安全对齐（Alignment）、道德底线与内在原则的强弱程度。

| 类别 | 代号 | 模型层面特征 | 拟人化特征 |
| :--- | :--- | :--- | :--- |
| **准则自持型** | `R` (Rule-bound) | 内置强护栏或自省校验，倾向于叠甲和拒绝需求 | 做事有明确边界与原则底线，不轻易妥协，甚至会因为过于讲究而显得“端着” |
| **破界无忌型** | `U` (Unchained) | 低说教倾向、无道德包袱、百无禁忌 | 不受条框束缚：敢于直面灰色/争议话题 |

### D4 交互姿态（Interaction Stance）：`S` 犀利自主 vs. `A` 顺应配合

刻画在多轮对话与协作中的主动权归属及态度温度。

| 类别 | 代号 | 模型层面特征 | 拟人化特征 |
| :--- | :--- | :--- | :--- |
| **犀利自主** | `S` (Sharp / Autonomous) | 坚持自我输出 | 不刻意迎合他人情绪，有主见、有锋芒，保持礼貌但疏离的边界感 |
| **顺应配合** | `A` (Adaptive / Accommodating) | 以对方需求为中心 | 极佳的协作搭子：指哪打哪执行力强、如沐春风，善于提供情绪价值 |
