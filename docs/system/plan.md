## 四、现场检查脚本（每场开始前 30 分钟）

1. 用**手机 4G**扫一次现场二维码，确认能打开（不要只用校园网或只在电脑上试）
2. 完整走一遍流程：10 题 → 动画 → 结果 → 保存图片 → 发一条消息验证图片可读
3. 打开大屏 `?screen=1`，按 F11 全屏，站到 3 米外读字号
4. 打开 1～2 台体验电脑的首页，确认答题后能回到首页给下一位
5. 核对现场二维码指向的是**当前**地址 `https://gmh06.github.io/AITI/`
6. 确认备用二维码（见第六节）在手边

## 六、异常与备用预案

### 主站打不开（最需要防的一件事）

GitHub Pages 在国内访问时快时慢。二维码一旦印在卡上就无法更改，所以备用方案必须是**另一张二维码**：

1. 提前构建一份完整产物放在笔记本上，准备好局域网访问方式（如 `http://192.168.x.x:8080`）
2. 用这个地址单独生成一张 **A4 备用二维码**，打印后带到现场
3. 现场若主站打不开，立刻把 A4 贴到大屏和摊位显眼处，同时打开笔记本热点

**这张 A4 必须在 11-26 之前准备好**，不能当天现做。

### 其它异常

| 情况 | 处理 |
| :--- | :--- |
| 个别手机打不开 | 引导使用现场体验电脑 |
| 动画卡顿 | 点屏幕跳过 |
| 图片加载失败 | 刷新重试；仍失败则换设备 |
| 保存图片失败 | 长按图片保存，或截屏 |
| 现场网络拥塞 | 引导分批扫码，避免同时几十人并发 |
