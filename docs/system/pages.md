# 页面与交互

站点的屏幕构成、状态切换、逐屏元素与揭晓动画的分镜。系统形态见[系统总览](overview.md)，文案与数据见[内容与版本](content.md)，实现见[技术方案](tech.md)。

## 一、页面清单与状态机

单页应用，不使用路由。全部流程在一个页面内以状态切换完成；大屏是独立入口。

| 状态 | 进入方式 | 说明 |
| :--- | :--- | :--- |
| `intro` | 默认 | 首页 |
| `quiz` | 点「开始」 | 10 道题，逐题推进 |
| `reveal` | 第 10 题作答后 | 揭晓动画，3.0 秒 |
| `result` | 动画结束或点击跳过 | 结果页 |
| `card` | 结果页点主按钮 | 电子卡页 |
| `screen` | 访问 `?screen=1` | 大屏轮播，与答题流程无关 |

```
intro ──开始──▶ quiz(1..10) ──▶ reveal ──▶ result ──▶ card
  ▲                                  │         │
  └──────────── 再测一次 ◀────────────┴─────────┘
```

**异常规则**：任何状态下刷新或关闭页面，都回到 `intro`，作答进度不保留。这是明确的产品决定，不做续答恢复。

## 二、逐屏设计

### 1. `intro` 首页

| 元素 | 说明 |
| :--- | :--- |
| 标题 | AITI |
| 副标 | Beyond Context 字标（透明底 PNG） |
| 一句话玩法 | 「10 道题，看看你是哪一个 AI」 |
| 主按钮 | 「开始测试」 |
| 辅助小字 | 「约 1 分钟 · 不需要填任何信息」 |

无任何输入框——不填昵称是这个活动的前提。

### 2. `quiz` 答题

| 元素 | 说明 |
| :--- | :--- |
| 顶部 | 进度条 + 题号 `3 / 10` |
| 左上 | 返回箭头（可回退上一题并修改答案） |
| 题干 | 场景描述，含加粗的题目标题「【凌晨两点的 FIT 楼机房】」 |
| 选项 | 四个竖排按钮，含 A/B/C/D 前缀 |

**交互**：选中选项即自动进入下一题，不设「下一题」按钮，减少一次点击。答题过程中**不显示对错或倾向反馈**，避免影响后续选择。

### 3. `reveal` 揭晓动画

全屏，3.0 秒，分镜见第三节。点击任意位置立即跳到结束帧。

### 4. `result` 结果页

自上而下：

| 顺序 | 元素 | 说明 |
| :--- | :--- | :--- |
| 1 | 角色插画 | 无文字版，约占视口高度 45% |
| 2 | 人格名 | 大字号，如「硬核工程师」 |
| 3 | 副标 | `GPT · LDRS` |
| 4 | 四维倾向 | 四条横向条，见第四节 |
| 5 | 描述 | 该人格的完整描述，约 200 字以上，不截断 |
| 6 | 主按钮 | 「查看我的纪念卡」 |
| 7 | 页脚 | `11月29日 · 大礼堂` |

### 5. `card` 电子卡页

| 元素 | 说明 |
| :--- | :--- |
| 卡面图 | 该人格对应的分享图，正反面已排在同一张图上 |
| 主按钮 | 「保存图片」 |
| 提示 | 「手机上长按图片也可以保存」 |
| 次按钮 | 「再测一次」→ 回 `intro` |

卡片的设计与出图不在本站范围内，网页只负责展示与下载。

### 6. `screen` 现场大屏

访问 `?screen=1` 进入。1920×1080 全屏轮播，无需交互，自动循环：

1. 主视觉 + 活动名
2. 玩法说明（三行以内）
3. 8 个角色剪影/亮相
4. 大二维码 + 一句行动号召

不做实时数据、不做统计看板。

## 三、揭晓动画分镜

从 `0.6s` 起重噪声开始收敛时，画面已经在 **5.5 倍裁切视图**上，去噪完成即得到局部特写；拉远是把同一个元素从 5.5 倍缩回 1 倍。

| 时间 | 阶段 | 画面 | 实现要点 |
| :--- | :--- | :--- | :--- |
| 0.0–0.1 | 噪声建立 | 全白页面中央浮现颗粒噪声，约占屏宽 70% | SVG `feTurbulence` 叠加，种子每 40ms 变化 |
| 0.1–0.5 | 噪声跳动 | 噪声持续变化，顶部小字淡入 | 文案 opacity 0→1，300ms |
| 0.5–0.6 | 蓄力 | 噪声幅度短暂增强，一次明暗脉动 | `feDisplacementMap` scale 80→100→80 |
| 0.6–0.8 | 去噪开始 | 噪声收敛，底层图像从模糊中浮现 | displacement 100→0（400ms）；blur 40→24 |
| 0.8–1.1 | 去噪中段 | 色块出现结构，仍认不出内容 | blur 24→10；顶部文案切换 |
| 1.1–1.2 | 去噪完成 | 画面完全清晰 | blur 10→0 |
| 1.2–1.6 | 特写静止 | 局部特写定格，只做极轻呼吸 | scale 5.50→5.61（相对 +2%），linear |
| 1.6–1.9 | 猛拉远 | 画面急剧缩回全身 | scale 5.61→1.0（300ms，`cubic-bezier(0.16,1,0.3,1)`）；blur 24→0；闪白 opacity 0.5→0（120ms） |
| 1.85–1.95 | 过冲 | 落到 0.97 | 100ms |
| 1.95–2.05 | 回弹 | 回到 1.0 | 100ms |
| 2.0–2.4 | 定格 + 人格名 | 角色静止，人格名落下 | 人格名 translateY −12px→0 + 淡入，400ms；字距 0.2em→0.05em |
| 2.4–2.7 | 四维条就位 | 四条依次填充到目标长度 | 每条 300ms，间隔 80ms |
| 2.7–3.0 | 描述淡入 | 描述文字上移淡入 | 400ms |

**过程中文案**：
- 0.1–1.1：`正在读取你的 10 个选择…`
- 1.1–1.2 起淡出，特写阶段完全留白

### 为什么结尾不跳变

动画不是独立遮罩层，而是**结果页里那张角色图自身的入场变换**：它在同一个 DOM 节点上，从「5.5 倍放大 + 模糊 + 位移」变回本来的位置。因此动画结束帧就是结果页第一帧，不需要切换，也不会闪一下。

### 必须支持的降级

| 情况 | 行为 |
| :--- | :--- |
| 目标角色图未加载完 | 停在噪声阶段，文案继续显示；加载完成后才进入去噪 |
| 点击 / 触摸任意位置 | 立即跳到结束帧，直接进 `result` |
| `prefers-reduced-motion: reduce` | 跳过动画，直接显示结果页 |
| 连续掉帧超过阈值 | 降级为「淡入 + 轻微缩放」的简版 |

## 四、四维倾向的呈现

四个维度各一条横向条，只表达**方向与强弱**，不显示原始分数。

| 元素 | 说明 |
| :--- | :--- |
| 左 | 维度名：认知内核 / 思考倾向 / 对齐模式 / 交互姿态 |
| 中 | 条形，长度 = \|得分\| / 7，向对应方向延展 |
| 右 | 档位文字 + 极名，如「明显 · 人文表达」 |

档位与条长的换算规则见[内容与版本](content.md)第三节。

特写要「有辨识度但看不出是谁」。除 DeepSeek 与 Gemini 取自角色自身外，其余只取道具，尽量少暴露角色部位。

| GPT | 图纸一角：图框、细网格、折角 | 道具 |

| Kimi | 手风琴折页的连续折痕 | 道具 |
| Gemini | 一只眼睛（异色瞳） | 角色自身 |
| GLM | 键盘，几个键帽被压住 | 道具 |

## 六、异常与边界

| 情况 | 行为 |
| :--- | :--- |
| 答题中途刷新或关闭 | 回首页，进度作废 |
| 未作答点回退 | 允许，回到上一题可改答案 |
| 重复点击「开始」或按钮 | 防抖 300ms，只响应一次 |
| 结果页刷新 | 回首页，不恢复结果 |
| 角色图加载失败 | 显示纯色占位 + 「图片加载失败，请刷新」 |
| 微信内打开 | 功能一致；保存图片走长按，不保证「保存图片」按钮行为一致 |

## 七、可访问性

- 所有可点区域不小于 44×44px
- 正文与背景对比度不低于 4.5:1
- 动画可跳过，且尊重 `prefers-reduced-motion`
- 选项按钮使用可聚焦的元素，支持键盘操作（现场电脑可能用键盘）
