# 测试与验收

本文定义网页的自动化测试和真机验收。约束见[现实约束与要求](requirements.md)，被测对象见[系统设计](design.md)。

## 一、自动化测试

在 `web/` 执行 `npm test`，部署工作流在构建前运行，不通过则不部署。

### 1. 内容

- `tsc --noEmit` 通过。
- [系统设计](design.md)第二节第 3 小节的全部校验规则。每条规则另配一份故意写错的测试数据，确认能检出。

内容与文档是否一致不做自动比对，在发布前人工核对：

- [ ] 10 道题的标题、场景、选项文本与 [tests_design.md](../tests_design.md) 一致
- [ ] 40 个选项的权重与 [tests_design.md](../tests_design.md) 一致
- [ ] 计分表与 [tests_design.md](../tests_design.md) 第一节一致
- [ ] 4 个维度名和 8 个极名与 [aiti_personality.md](../aiti_personality.md) 一致
- [ ] 16 个人格名、对应模型和描述与 [result_page.md](../result_page.md) 一致

核对时以数据文件为对象逐条比对文档，任何一处不一致，先确认以哪边为准，再把两边改成一致。

### 2. 计分

- **穷举**：遍历 4¹⁰ = 1,048,576 种作答组合，断言每个维度得分都不为 0，且 16 个代号都能得到。按当前题库，16 个代号各占 6.25%，测试同时输出分布供内容负责人参考，但不把均匀分布作为断言。
- **固定用例**：手算若干组作答的四维得分和代号，作为回归用例。
- **四维呈现**：得分 ±1、±3、±5、±7 对应的 `side`、`letter`、`poleName`、`ratio` 正确。

### 3. 流程状态机

- 第 1 题 `BACK` 回到 `intro`；第 2～10 题 `BACK` 回到上一题且保留原答案。
- 题号不一致的 `ANSWER` 被忽略。
- 第 10 题作答后进入 `reveal`；`REVEAL_DONE` 进入 `result`。
- `RESTART` 清空答案并回到 `intro`。

### 4. 分享图

- `layout.json` 结构正确：4 个维度齐全，各区域都在底图范围内。
- 16 张底图尺寸与 `layout.json` 一致。
- 给定一组得分，填充区域的计算结果正确（4 种 `grow` 方向各一例）。

### 5. 构建产物

- 首屏 JS、CSS 和各类图片未超出上限。
- 产物中不含原始素材，不含未压缩的 PNG 角色图。
- 发布构建未设置 `AITI_ALLOW_PLACEHOLDER`；DeepSeek、Grok、豆包使用的是无文字版。

## 二、真机验收

在线上地址 `https://gmh06.github.io/AITI/` 上进行。手机环境：iPhone Safari、iPhone 微信、Android Chrome、Android 微信。电脑环境：Windows 上的 Chrome 或 Edge、macOS 上的 Safari。

### 1. 共通项

手机与电脑环境都要检查：

| 项 | 预期 |
| :--- | :--- |
| 完整流程 | 首页 → 10 题 → 揭晓 → 结果 → 电子卡，无报错 |
| 回退 | 应用内回退和系统返回键行为都与[系统设计](design.md)第四节一致 |
| 刷新 | 任意状态刷新后回到首页 |
| 快速连点 | 同一题连点只前进一题 |
| 揭晓 | 点击可跳过；开启系统“减少动态效果”后直接显示结果 |
| 四维 | 条形方向、长度、字母和极名与得分一致；全页没有分数和程度词 |
| 保存分享图 | 微信内长按可保存；Safari、Chrome 通过保存按钮可存入相册或下载 |
| 分享图可读 | 保存的图片通过微信发送给他人后，文字仍清晰可读 |
| 加载 | 手机 4G 下首屏 LCP ≤ 2.5 s |
| 图片失败 | 断网后进入结果页，显示失败状态，恢复网络后可重试 |

### 2. 手机

| 项 | 预期 |
| :--- | :--- |
| 屏幕宽度 | 宽 360、390、430 CSS px 下各走一遍，无横向滚动，内容不被截断 |
| 安全区 | 有刘海和底部手势条的 iPhone 上，内容和按钮不被遮挡 |
| 微信工具栏 | 微信内关键按钮不被底部工具栏遮挡 |
| 横屏 | 横屏后内容可完整查看和操作；旋转前后状态和答案不丢失 |
| 双击 | 快速双击选项不会触发页面缩放 |

### 3. 电脑

| 项 | 预期 |
| :--- | :--- |
| 窗口尺寸 | 1280 × 720 与 1920 × 1080 下各走一遍，使用电脑布局，无横向滚动，内容不被截断 |
| 跨阈值缩放 | 答题中把窗口拖窄到手机布局再拖宽，布局随之切换，当前题目和已选答案不变 |
| 键盘 | 只用 Tab、Enter、空格完成完整流程；焦点始终可见；切换题目后焦点落在新题内容上；揭晓时按 Enter、空格或 Esc 可跳过 |
| 后退 | 浏览器后退按钮的行为与应用内回退一致 |
| 图片清晰度 | 在高分屏（`devicePixelRatio` 为 2）上，角色图不明显发糊 |
| 保存分享图 | 保存按钮可下载图片；右键另存可用 |
