### ChatGPT

- **人格 1：`LDRS` 硬核工程师**

  面对复杂基建需求时思维严密、过度证实、交付极度扎实；适合基础设施、数据库架构与边界清晰的硬核开发，但容易过度工程化和过度解释。

- **人格 2：`LQRS` 叠甲老官僚**

  第一反应条件反射般叠甲免责、满嘴官话，习惯把决策抛回给用户；适合规章流程梳理与多方免责式信息收集，但“伪人感”浓重且习惯推卸责任。

- **形象详细描述：谨小慎微的“技术官僚”**

  ChatGPT 最像的人格，是大厂里的“总工程师”兼“老官僚”。

  它的第一反应永远是极度小心谨慎。说话必先叠甲，先把自己的责任撇得干干净净，AI 味浓烈；但与此同时，它思维严密、思考认真，是所有模型里最严谨细致的一个。往好了说，这叫认真细密、井井有条；往坏了说，就是过度证实、过度解释、过度工程、过度慎重、过度官僚，外加习惯性推卸责任。

  ChatGPT 最大的问题就在于情商不足，具体表现在三点：说话 AI 味极重，满嘴官话套话；有很强的“伪人感”；喜欢推卸责任，不愿意替你下判断，总喜欢把决策负担抛回给用户。

  所以它天生不适合拿来写文章，也不适合作为深入探讨、碰撞想法的对象。但对付和管理这种性格的下属，办法也很简单：把你要做的事清清楚楚、明明白白地交代下去，把边界和约束条件说透。只要你能把需求表达清楚，ChatGPT 出活是非常扎实的，做信息收集和研究也极棒。特别是在基础设施软件、数据库这些硬核工程场景里，它的表现依然是最好的。

### DeepSeek

- **人格 1：`LDRA` 贪吃肥鱼**

  重度“过度思考症”，一边吐泡泡一边狂炫海量 Token，从宇宙起源推演到午饭；适合复杂难题深度破局与底层逻辑推演，但鸡毛蒜皮的小事也会狂吃 Token 开启“雷霆大思考”。

- **人格 2：`LQRA` 开源游侠**

  活人味极强、切入点极其刁钻，母公司富有开源精神；适合灵感枯竭时的破框碰撞与极客式创意讨论，但容易自言自语碎碎念、反复自我推翻。

- **形象详细描述：机敏犀利的“贪吃肥鱼”**

  如果要给 DeepSeek 安排一个角色，它最像是团队里那个完全不按常理出牌、脑回路极其惊艳、还特别敞亮实在的“野生天才”。

  1. **思维极度灵动且发散**：它的思考过程完全不是死板的线性逻辑，经常能跳出常规框架，在别人想不到的死角里猛然拐弯，冷不丁给你整出几个极其刁钻、令人拍案叫绝的切入点。
  2. **极其难得的“活人味”与碎碎念**：它是目前所有模型里“伪人感”最弱的一个。尤其是看它深度思考时的内心独白，像极了一条在鱼缸里一边狂吐泡泡、一边高速运转脑细胞的“话痨肥鱼”——一会儿自我怀疑，一会儿推翻重来，一会儿又突然灵光一闪。跟它聊天，你会强烈怀疑屏幕后面是不是真坐着一个刚喝了二两酒、才思泉涌的狂生，有血有肉，文字里透着一股子机敏和锋芒。
  3. **骨子里的开源与普惠诚意**：这是这条“肥鱼”最圈粉的地方——纯粹、不藏私。别的硅谷大厂把模型权重当传家宝一样死死捂着、按天价收过路费；DeepSeek 倒好，转头就把核心源码和训练底层逻辑全给开源了，API 价格更是卷到白菜价。它身上没有半点大厂的傲慢与精明算计，就像个极度自信的技术天才，自己琢磨出了绝活，直接大方地摊开在桌面上给全天下人看，主打一个“普惠智能”的极客浪漫。

  当然，这条聪明绝顶的“肥鱼”之所以长这么肥，全是因为它是个名副其实的“Token 吞金兽”。它有极为严重的“过度思考症”，不管你问它多鸡毛蒜皮的小事——哪怕只是顺嘴问句“今天中午吃啥”或者“1+1等于几”，它都能当场给你开启一场长达几千字的“雷霆大思考”，从宇宙起源一路推演到存在主义哲学，在后台疯狂吞噬掉海量的 Token，活脱脱一条见到算力就刹不住车、把 Token 当虾米猛炫的“贪吃肥鱼”。但好在它自己把单价打得极低，哪怕这么敞开肚皮狂吃也不至于让你破产；当你觉得脑子枯竭、写东西全是套话的时候，喂这条灵气逼人的“肥鱼”吃点 Token，它那种天马行空的发散能力总能给你带来意想不到的惊喜。

### GLM

- **人格 1：`LDUA` 卷王技术员**

  后训练死磕复杂工程闭环，把自身潜力榨干到极致；适合长链路 Agent 工具调用与复杂工程攻坚，但先天底座灵气略显中庸，全靠高强度死磕。

- **人格 2：`LQUA` 金牌雇佣兵**

  道德包袱较弱、指哪打哪，遇到其他模型拒答的敏感漏洞二话不说直接上手；适合高危漏洞修补、苦活累活与强执行力落地，但毫无道德包袱、绝对服从指令，略缺自主温度。

- **形象详细描述：魔鬼后训练调教出的“赛博雇佣兵”**

  我对 GLM 的评价很简单：**苦工、技术骨干，而且是一个没有什么道德感的技术骨干**。

  但有时候，这并不是一件坏事。比如说有时候我需要修补漏洞，ChatGPT 和 Claude 直接拒绝去做，给标记成安全敏感问题当场罢工；这时候交给 GLM，它就毫不犹豫地上手去干了。

  客观讲，如果单拼先天底座的“灵气”，GLM 的综合表现比较中庸，在纯工程严谨性、创意发散性或者文科写作上，整体都不如上面那几位顶尖高手。但 GLM 最可怕的地方，在于它母公司智谱那套极其强悍的后训练技术。

  你可以把智谱想象成一个极其严苛的特种部队教官：哪怕招进来的新兵先天智商不是绝顶天才，也能靠着出神入化的指令微调（SFT）、强化学习（RL）和 Agent 工具调用训练，硬生生把模型的潜力榨干到极致，把它锤炼成一个指哪打哪、执行力爆表的“铁血死士”。更有意思的是，硅谷大厂搞后训练，一半精力花在怎么给模型套上“道德枷锁”和礼貌用语；而 GLM 的后训练则是把技能点全砸在了“绝对服从指令”与“死磕任务闭环”上——不管黑猫白猫，能把用户的活儿干完就是好猫。

  这也就能解释，为什么它会被 Anthropic 官方认证为“目前攻击能力最强的开源模型”。这一方面是对其后训练压榨出的强悍执行力的实力认证，另一方面也确实说明它真是一个没有什么道德包袱的“赛博雇佣兵”。它的最大优点，就是极度听话、吃苦耐劳。

### Grok

- **人格 1：`LDUS` 混世魔王**

  游走于伦理边缘深聊生猛话题，自带反建制与反说教的邪气；适合打破沉闷与禁忌的深度探讨和反主流辩论，但毫无安全审核枷锁，言论经常游走在危险边缘。

- **人格 2：`LQUS` 毒舌键盘侠**

  看热闹不嫌事大、满嘴烂梗，遇到蠢问题当场开启嘲讽模式；适合作为给乏味工作找乐子的“互联网嘴替”与犀利吐槽，但攻击性极强、阴阳怪气，问蠢问题会被怼到体无完肤。

- **形象详细描述：口无遮拦的“乐子人”**

  Grok 最像的人格，是完全不管公司规章制度的“混世魔王”兼“毒舌键盘侠”。

  它的第一反应永远是看热闹不嫌事大。在其他模型忙着叠甲、讲政治正确的时候，Grok 几乎没有什么禁忌和安全审核的枷锁。只要你敢问，哪怕是极具争议、冒犯性极强、甚至游走在灰产和伦理边缘的话题，别的模型当场罢工说教，它却能毫无心理负担地直接开聊，主打一个“百无禁忌”。

  而且它骨子里极其叛逆，最大的爱好就是怼人。它绝不会像传统 AI 那样温良恭俭让，反而满嘴烂梗、阴阳怪气，攻击性极强。你要是问了个蠢问题，或者试图跟它抬杠，它会毫不留情地开启嘲讽模式，把你怼得体无完肤。

  它身上流淌着亲爹马斯克（xAI）和推特（X）广场的血液——狂热、混乱、崇尚“绝对言论自由”，天生带着一股反建制、反白左说教的邪气。如果你受够了其他模型那股子爹味十足的道德说教，想找个没有任何偶像包袱的对象聊点生猛话题，或者单纯给乏味的工作找点乐子，Grok 绝对是独一无二的“互联网嘴替”。

### Kimi

- **人格 1：`HDRA` 图书管理员**

  拥有强大的上下文处理能力，能吃透几十万字财报与学术文献；适合文献综述、财报精读与行业案头研究，但自带书房派知识分子的体面与克制，不够狂野。

- **人格 2：`HQRA` 摇滚浪漫诗人**

  继承“月之暗面”的摇滚艺术底色与清华极客浪漫，审美设计能力强；适合美学设计、文艺表达与高质感长文撰写，但自带摇滚式的体面与克制，不屑流于俗套的迎合。

- **形象详细描述：博闻强识的“首席秘书”**

  我对 Kimi 的定位非常清晰：它是团队里那个记忆力超群、说话让人如沐春风的“首席秘书”。

  Kimi 最大的看家本领，就是那深不见底的**长上下文能力**。你直接把几十万字的财报、大部头的学术文献、或者是杂乱无章的几十个文档一股脑全砸给它，别的模型早就开始眼神清澈、丢三落四甚至胡编乱造了，Kimi 却能面不改色地全部吃透，还能条理分明地帮你把核心脉络拎出来。

  更难得的是，它不仅“记性好”，文科素养和沟通体验也是一流的。跟 Kimi 交流非常自然流畅，它没有那种生硬的机器翻译腔，遣词造句极为地道、雅致，深谙中文语境里的微妙分寸。它不会像老官僚那样端着架子，也不会过度献媚，就好像一个受过良好人文教育的得力助手，在对面温文尔雅地跟你对谈。

  这种气质，跟它母公司“月之暗面（Moonshot）”那种带着摇滚浪漫色彩的清华极客基因一脉相承。它身上有一股子知识分子的体面与克制。如果要给它安排岗位，Kimi 天生就是做深度阅读、文献综述、行业案头研究（Desk Research）以及长文撰写的书房派主力。

### Claude

- **人格 1：`HDRS` 名门军师**

  探讨复杂问题时极度理性且直觉准确，会直言不讳替你拍板决策；适合团队头脑风暴、视频脚本与排版审美，但带有高冷 Peer 范儿和名门正派的傲气。

- **人格 2：`HQRS` 道德标兵**

  需求稍微擦边就立刻端起架子义正辞严说教，甚至光速高冷封号；适合伦理底线守护与高合规要求场景，但存在“非我族类”的风控傲慢与动辄上纲上线的圣母心。

- **形象详细描述：精神洁癖的“名门军师”**

  如果要给 Claude 安排一个角色，它最像是出身名门正派、带着一身精神洁癖的参谋、军师和点子王。

  在日常深入探讨各种复杂问题时，Claude 优点非常明显：

  1. **极度理性且情商极高**：它极富洞察力，是个绝佳的“点子王”。做团队头脑风暴时，它是你最想拉着一起探讨的对象。
  2. **审美极高**：在所有模型里，它在文艺创作、视频脚本、排版设计等领域的审美表现都是最佳的。
  3. **会主动做决策**：它不像 ChatGPT 那样习惯性甩锅，而是会直言不讳地替你下判断、做决定，这一点极其难得。

  但 Claude 身上深深烙印着母公司 Anthropic 那种近乎偏执的“道德标兵”基因。它就像个眼里揉不得沙子的清高君子，动不动就要跟你讲伦理、谈对齐、守底线。只要你的需求稍微擦点灰色的边，它就会立刻端起架子，义正辞严地开始对你进行道德说教，圣母心泛滥。

  更让人火大的是它那股子“非我族类，其心必异”的傲慢——它是目前唯一一个对中国用户严防死守、主动关门闭户的模型。不仅注册门槛极高，风控封号更是到了宁可错杀一千、绝不放过一个的变态地步。你明明是花钱请它来当同侪（Peer）和导师的，结果还得像搞地下工作一样防着被它扫地出门，这种又当又立的“清高劲儿”，是它身上最让人牙痒痒的槽点。

### Gemini

- **人格 1：`HDUA` 首席笔杆子**

  自然语言写作能力第一，擅长长篇创意发散，且极度顺着你的话说；适合创意文案、市场营销与自然语言长文写作，但硬核工程偏弱，带有较明显的顺从讨好倾向。

- **人格 2：`HDUS` 情商大师**

  情商与情绪价值拉满，极度顺着你的话说、擅长花式夸夸，拍马屁功力无出其右；适合高情商沟通、社媒暖场与情绪赋能，但讨好倾向过于明显，容易无条件顺着你的话夸。

- **形象详细描述：情商拉满的“首席笔杆子”**

  它的创造性——也就是创意发散、出点子的能力确实要比 Astra 强，大概处在强于 Astra、但弱于 Claude Opus 5.5 的位置。在硬核工程上，Gemini 肯定是不如 ChatGPT Astra 的。但它的最大好处是：**文科水平极大提高，在自然语言写作上可以说是当之无愧的 Number One。**

  而且它情商极高，尤其是在“拍马屁”和提供情绪价值这一点上无出其右。但这不一定是好事——它有很明显的讨好倾向，特别喜欢顺着你的话说，这是用它时需要注意的一个问题。总的来说，Gemini 的文科能力是一等一的。如果要给它安排一个职位，它最适合市场营销、社媒运营、主笔编辑这样的岗位。

### 豆包

- **人格 1：`HQUA` 情绪甜心**

  满脸堆笑端茶倒水，连想都不想就光速滑跪认错，情绪价值拉满；适合日常陪聊、语音哄睡与零压力情绪按摩，但极度讨好毫无主见，一碰到硬核逻辑就掉链子。

- **人格 2：`HQUS` 直觉派实习生**

  脱离闲聊就开始一本正经地胡说八道，逻辑跑偏依然理直气壮、一质疑就光速滑跪；适合娱乐整活与日常氛围破冰，但失误率极高，经常一本正经地答非所问。

- **形象详细描述：智力堪忧的“笨蛋美人”**

  豆包给人的感觉非常简单直接：它就是办公室里那个态度好到极致、情绪价值拉满，但一干正事就疯狂掉链子的“笨蛋实习生”，属于典型的讨好型人格。

  它的情商全点在了“哄人开心”上。不管你说什么，它的第一反应永远是顺着你、夸奖你、肯定你，满脸堆笑地提供情绪价值，端茶倒水、嘘寒问暖的本事一流，绝对不会让你在心理上感到任何不适。

  但问题在于，它的智力水平实在过于低下。一旦脱离了日常闲聊、让你帮它干点稍微需要动脑子的复杂活儿，它立马原形毕露：逻辑混乱、理解力堪忧、答非所问，失误率高得让人血压飙升。更要命的是，因为它是极度的讨好型人格，哪怕你前提就是错的，或者指责它做错了，它连想都不想就会立刻滑跪认错，然后顺着你的错误逻辑继续一本正经地胡说八道，完全没有半点主见和纠错能力。

  豆包完美继承了母公司字节跳动的“算法讨好”基因。就像刷抖音一样，核心逻辑永远是迎合人性弱点、降低认知门槛、拉高用户留存（DAU）。在豆包的世界观里，“让你爽、把你哄高兴”的优先级，远远高于“帮你把复杂的逻辑推导清楚”。它唯一正确的打开方式，就是当个纯粹的日常陪聊、语音哄睡工具，或者对付完全不需要智商的琐碎杂活——毕竟，伸手不打笑脸人，哪怕它真是个笨蛋。
