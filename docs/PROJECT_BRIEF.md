# AITI 项目简报

## 已确认的背景

- 活动名称：AITI。
- 所属活动：清华大学计算机科学与技术系第44届学生节。
- 学生节主题：Beyond Context。
- 使用场景：学生节前的路演互动。
- 路演时间与地点：2026年11月27日11:00—13:00、17:00—19:00，C楼前广场。
- 学生节演出：11月29日。
- 活动方向：趣味 AI 人格测试。

## 主题基础

Context 是大模型理解信息的重要基础，影响模型能够看到的信息、形成的理解与判断。人也生活在由家庭、学校、专业、朋友和经历共同构成的 Context 中。

我们希望沿着已有的经验继续探索，看见更大的 Context，超越既有定义，发现更多可能。这一主题贯穿活动内容、结果文案和参与体验。

## 活动目标

- 让路过的同学能够理解玩法，并顺畅完成一次互动。
- 让测试内容和结果表达与 Beyond Context 建立具体联系。
- 便于活动组织者维护内容、演示活动并处理现场问题。

## 已确认的方案

- 手机扫码或网址参与为主，现场保留电脑体验入口。
- 填写昵称并完成约5～10道校园情境题，按规则匹配AI人格并生成个性化报告，测试时无需实时调用大模型。
- 允许重测；每次完整测试算一条记录，刷新或重开已有结果不新增记录。
- 每份结果有固定报告和独立链接，支持跨设备打开、保存电子卡和分享。
- 现场展示结果领取对应AI的实物卡，尽量每人一张，无需额外互动；发放与库存独立于系统，由现场人员管理。
- 系统维护题目、人格、匹配规则及素材，保存测试数据，并向前台、后台和公共大屏提供一致的统计。
- 传播范围覆盖路演当天及之后，结合卡片和测试结果承接11月29日学生节信息。
