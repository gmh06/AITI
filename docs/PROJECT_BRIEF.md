# AITI 项目简报

## 已确认的背景

- 活动名称：AITI。
- 所属活动：清华大学计算机科学与技术系第44届学生节。
- 学生节主题：Beyond Context。
- 使用场景：学生节前的路演互动。
- 活动方向：趣味 AI 人格测试。
- 共同筹划制作：gmh06 与高源（Zaogezi）。

## 主题基础

Context 是大模型理解信息的重要基础，影响模型能够看到的信息、形成的理解与判断。人也生活在由家庭、学校、专业、朋友和经历共同构成的 Context 中。

我们希望沿着已有的经验继续探索，看见更大的 Context，超越既有定义，发现更多可能。这一主题贯穿活动内容、结果文案和参与体验。

## 活动目标

- 让路过的同学能够理解玩法，并顺畅完成一次互动。
- 让测试内容和结果表达与 Beyond Context 建立具体联系。
- 让两位共同制作者能够维护内容、演示活动并处理现场问题。

## 需要共同确定的问题

以下问题尚需两位共同制作者讨论确定：

1. **测试对象与机制**：是把参与者映射为某种 AI／模型人格、由 AI 辅助生成参与者的人格描述，还是两者结合？
2. **参与方式**：采用选题、对话或其他形式？预计参与时长和现场演示方式是什么？
3. **内容与结果**：结果如何形成、如何解释、是否支持重测或分享？怎样体现不同 Context 下的可能性？
4. **实现与运行**：采用什么技术、是否调用模型服务、如何部署、网络异常时怎样继续展示？
5. **路演安排**：使用哪些设备、现场需要准备什么、由谁维护和引导？
